# ERP 多租户 SaaS

FastAPI + Vue 3 + MySQL，中心库 + 每租户独立业务库。桌面 `ventasync` Laravel 项目仅作为业务参考。

## 当前实现

- 平台创建租户、邀请负责人、全局账号加入多个租户。
- 多角色、店铺/库存地点数据范围、敏感字段过滤、操作审计。
- 每个租户的成员编号独立从1递增；停用、重邀或转移负责人保留编号，原权限及业务关联继续使用稳定内部ID。
- SPU—SKU商品中心：中英文资料、供应商/人员、尺寸、SKU多别名、三类成本/重量及销售状态汇总。
- SPU详情的基本信息、销售信息和字段操作日志；SKU别名贯通TikTok商品、订单与库存识别。
- 租户“基础设置 → 商品设置”集中维护供应商、品牌、分类、特性标签和包材；供应商联系人、联系方式、备注均选填。
- 平台系统配置：统一管理OSS/COS/OBS/AWS S3及S3兼容账号、测试连接、切换默认；密钥加密保存且不回显。
- 新图片上传至默认云对象存储，长期URL保存到数据库；基础字典、版本校验，以及库存余额与流水。
- Shopee、TikTok 店铺授权、现有商品读取及映射、订单同步、库存推送。
- 持久化任务、Outbox、独立 Worker 和调度器，权限与同步开关在执行时复核。
- 可复制、可撤销的长期授权入口；打开入口后生成短期一次性 OAuth state。

本轮实现和验证结果见 [验收记录](docs/acceptance.md)。线上部署见 [生产记录](docs/real-deployment.md)；SPU商品中心、系统配置和商品设置均已发布；对象存储需配置实际云账号并完成真实连通和图片访问验收，真实平台试点优先TikTok。在线商品调价、促销和完整刊登属于后续阶段。

## 开发与发布

后端安装 `backend/requirements-dev.txt`，配置自己的 `.env`。中心库与租户库迁移由独立发布任务执行，API 启动不自动迁移。迁移版本以 Alembic 实际版本图为准；当前中心库 `center_0009`、租户库 `tenant_0013`，共22个迁移文件，业务表为中心18张/租户32张。

本地后端入口保持 `uvicorn app.main:app --host 0.0.0.0 --port 8000`，前端在 `frontend` 执行 `npm run dev`；这些是手动启动说明，智能体不得擅自启动项目。

提交前执行相关后端回归、`python scripts/verify_contracts.py` 和前端 `npm run build`。`frontend/dist` 是受版本管理的服务器发布产物；仅审阅构建时可指定临时输出目录，正式发布应更新受管理产物。

## 硬性约束与待验收

- 所有应用表禁止外键，表与字段必须有中文注释；ALTER 修改后的最终模式也必须保留注释。
- 金额采用 DECIMAL/Decimal，时间存 UTC，大整数 ID 以 JSON 字符串输出。
- 首次真实推送保持关闭，在测试店铺和 SKU 映射核对完成后显式开启。
- 真 MySQL 并发、Worker 故障恢复、TikTok/Shopee 真店闭环及本轮迁移后的备份恢复仍需独立授权环境验收。
- 成员、店铺、商品/SKU 已接入套餐额度执行，真实MySQL并发验收待完成；新上传图片使用已配置的云对象存储，旧本地图片卷继续兼容；导出、在线支付、完整刊登及售后留待后续阶段。
- SKU当前/指导/平均成本本轮人工维护；SPU只汇总。别名租户内唯一，停用后保留归属；捆绑与组装类型尚不包含BOM或组装扣库存。

## 配置图片云存储

平台管理员进入“系统配置”，新增存储账号，填写Endpoint、Bucket、地域、访问密钥和长期HTTPS访问域名或CDN地址，保存后测试桶连接并设为默认。可同时保存多个厂商账号，切换默认只影响之后上传的图片。管理员需自行配置云端读权限和CDN；不使用会过期的签名URL作为商品地址。

新上传未配置或失败会明确报错，不回落本地。数据库保存上传结果中的对象键、厂商、账号ID与长期URL；SPU/SKU直接保存返回URL。历史本地文件仍从原持久化卷鉴权读取，本轮不自动迁移或删除。真实云上传、读权限和CDN访问仍需有效账号验证。
