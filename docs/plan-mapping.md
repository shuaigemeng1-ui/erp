# 原计划与当前实现对照

原始需求保留在根目录 `plan.txt`。本轮优先完成 SPU—SKU 商品中心，作为 TikTok 在线商品、调价和刊登的基础。既有生产发布记录见 `real-deployment.md`；本轮新增迁移与商品功能尚需按验收记录发布，不将本地回归当作真实店铺验收。

| 领域 | 当前实现 | 验收边界 |
| --- | --- | --- |
| 工程与无外键 | API/Vue/中心及租户迁移；完整版本图、最终SQL列和中文注释检查 | 本轮17个迁移文件；中心15/租户32张业务表 |
| 身份与权限 | 分库、开通、邀请、多角色范围、任务授权、角色防提权、成本字段控制 | 商品仍要求对应操作的全部范围，日志同步脱敏 |
| SPU基本资料 | 中英文名称、编号、供应商和三类人员、海关/材质/用途、字典、尺寸、类型、备注/特点、图片 | 捆绑与组装目前只记录类型，未建设BOM |

## 本轮增量迁移

`tenant_0011`（parent `tenant_0010`）：扩展SPU及SKU、审计关联，新增 `sku_identifiers/suppliers/catalog_options`，平台SKU编码扩至128字符，预检并回填历史SKU主编号及缺失当前成本。

中心库末端保持 `center_0006`，租户库末端为 `tenant_0011`；共17个实际迁移文件，全部业务表和字段中文注释，模型与最终离线SQL零外键。

升级前备份；在线Alembic迁移完成后再启用新代码。主键不变，不重新建商品、库存或订单；标准化编号存在冲突时先处理冲突，不静默跳过。指导/平均成本及重量没有历史来源时保持空。

## 后续交付顺序

1. TikTok在线商品同步、平台SKU标识和详情快照完善。
2. 单个与批量日常调价：预览、权限复核、执行记录和回读确认。
3. 固定活动价/折扣/秒杀、活动管理、上下架及状态核对。
4. 从本地SPU和SKU生成刊登草稿，完成站点类目/资质、商品编辑、发布与审核跟踪。
5. TikTok先覆盖美国、英国和欧盟具体国家店铺，按国家验收后开放；再接入Shopee写能力。

以上在线调价、促销和完整刊登仍属于后续工作，本轮商品中心不宣称已实现。采购自动成本、BOM/组装、结算、在线支付及其他渠道另行规划。
